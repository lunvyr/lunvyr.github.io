# Nature Soundscape
- 수면, 집중, 그리고 온전한 휴식을 위한 나만의 오디오 공간

Nature Soundscape는 일상에 지친 당신을 위해 디자인된 기능성 오디오 플레이어입니다. 숙면이 필요하거나, 고도의 집중력이 필요한 순간, 혹은 단순한 휴식이 필요할 때 백그라운드 사운드를 제공합니다.
단순히 소리를 듣는 것을 넘어, 내가 가장 좋아하는 오디오 패키지를 수집하고 나만의 라이브러리를 구축해 보세요.
